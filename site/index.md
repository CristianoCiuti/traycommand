features:
  - title: Toggles with live state
    details: A check script decides whether an entry is ON or OFF. The icon, the menu check mark and the editor follow it in real time.
  - title: Hide without deleting
    details: Hide a tray or a menu entry with one click and bring it back later. Disable entries to pause their state checks.
  - title: Test from the editor
    details: Every action and state check has a Test button that shows exit code, output and the resulting state before you save.
  - title: Start at login, no admin
    details: A plain shortcut in your Startup folder. No Task Scheduler, no registry, no administrator rights.
  - title: Per-user install, self update
    details: Installs into your user profile and updates itself from GitHub releases, verified with SHA-256.
  - title: Windows, Linux, macOS
    details: PowerShell, cmd, bash, zsh, sh or any custom shell. One configuration file you can share between PCs.
